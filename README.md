# Dashboard Analítico de Vendas Globais | Power BI

## 📌 Sobre o projeto

Esse foi meu primeiro dashboard desenvolvido durante o curso da Data Science Academy, utilizando o Power BI.

A proposta foi explorar uma base de dados de vendas globais e transformar essas informações em visualizações que facilitassem a análise dos resultados.

## 🎯 Objetivo

Analisar dados de vendas globais por meio de indicadores e visualizações, facilitando a compreensão dos resultados e a exploração das informações.

## 📊 Visualização do dashboard

![Dashboard Analítico de Vendas Globais](Dashboard%20Analitico%20de%20Vendas%20Globais.png)

## 🔎 Análises realizadas

* Total de vendas por categoria de produto.
* Média de desconto por subcategoria.
* Vendas por país e prioridade.
* Distribuição geográfica das vendas.
* Filtros para explorar os dados por ano, segmento e país.

## 📚 O que aprendi

Esse foi meu primeiro projeto de dashboard no Power BI e foi uma experiência muito importante para colocar em prática o que venho aprendendo.

Durante o desenvolvimento, pude explorar diferentes tipos de gráficos, analisar as vendas por categorias e países e trabalhar com indicadores, como total de vendas e média de desconto. Também aprendi mais sobre como utilizar filtros para explorar os dados de diferentes formas e tornar o dashboard mais interativo.

Além de aprender mais sobre o Power BI, esse projeto me ajudou a entender melhor como organizar e apresentar informações de forma visual, facilitando a análise dos dados.

## 🚀 Próximos passos

Esse projeto faz parte da minha jornada de aprendizado em análise de dados e da construção do meu portfólio. Quero continuar praticando, desenvolvendo novos dashboards e aprimorando meus conhecimentos em Power BI.
